# 정보 서랍

기기에 저장하는 메시지·링크·사진·공지·아이디어 PWA. GitHub Pages용 정적 앱이며 OpenAI, 외부 AI, 원격 데이터베이스를 사용하지 않습니다.

## 아이폰 설치

1. Safari에서 배포된 HTTPS 주소를 엽니다.
2. 공유 → 홈 화면에 추가. 웹 앱으로 열기 옵션이 있으면 켭니다.
3. 인터넷에 연결된 상태에서 홈화면 아이콘으로 앱을 한 번 더 엽니다.
4. 로컬 보관 → 오프라인 준비 완료를 확인합니다.
5. 비행기 모드에서 앱을 닫았다가 다시 열어 저장·검색을 확인합니다.

추가 인증서, 프로파일, PC 서버는 필요하지 않습니다. 초기 앱 파일 다운로드, 브라우저의 서비스 워커 업데이트 확인, 재설치는 인터넷과 호스팅이 필요합니다. 준비 후의 페이지 읽기는 서비스 워커 캐시에서 처리합니다. 오프라인 사용 가능 여부는 실제 기기에서 확인하세요.

## 개인 자료와 외부 통신

기록·사진은 이 웹주소의 IndexedDB에 저장됩니다. 공개 저장소에는 빈 앱 파일만 있으며 사용자의 기록·사진·백업·인증서·개인키는 포함하지 않습니다. 로그인이나 서버 업로드 API가 없습니다. 기록 저장·검색·분류·백업 암호화는 브라우저 안에서 실행합니다.

HTML의 CSP는 connect-src none, 원격 이미지·프레임·폼 전송 차단을 적용합니다. 서비스 워커는 설치 시 같은 앱 경로의 파일만 받고 이후에는 캐시에서 응답합니다. GitHub Pages에서 제어할 수 없는 서버 헤더 대신 문서 CSP를 사용하며, 스크립트는 프레임 안에서 개인 저장소를 열지 않습니다. GitHub Pages는 앱 파일 접속을 처리하므로 IP 주소 등 접속 정보가 전달될 수 있습니다. 운영체제·브라우저·확장 프로그램 자체의 통신까지 이 앱이 막지는 못합니다.

원문 링크는 사용자가 선택할 때 외부 창으로 열립니다. 백업을 공유하거나 클라우드에 저장하는 동작도 사용자가 직접 선택합니다. 기기 원본은 암호화되지 않으며 내보내는 백업만 암호화할 수 있습니다.

## 백업과 이동

백업 → 암호화 옵션 → 비밀번호 입력·확인 → 파일 저장. 지원되는 아이폰에서는 파일 앱에 저장 / 공유 버튼도 사용할 수 있습니다. 로컬 보관을 원하면 나의 iPhone을 저장 위치로 선택하세요. AES-256-GCM / PBKDF2-SHA256 600,000회를 사용합니다. 비밀번호를 잊으면 복원할 수 없습니다.

기존 localhost 또는 집 Wi-Fi HTTPS 앱과 이 사이트는 저장 공간이 다릅니다. 기존 앱에서 백업한 뒤 이 웹주소의 홈화면 앱에서 복원하세요. 기존 인증서 프로파일은 필요하지 않으므로 다른 용도로 쓰지 않으면 아이폰 설정 → 일반 → VPN 및 기기 관리에서 해당 Info Drawer Local 프로파일을 직접 제거할 수 있습니다.

브라우저 데이터 삭제·기기 고장·저장 공간 정리에 대비해 별도 백업을 보관하세요. 사진 1장 20MB, 기록당 20장, 가져오는 백업 파일 100MB 한도가 있습니다. HEIC/HEIF는 기기가 디코딩할 수 있는 경우 최대 2560px JPEG로 변환합니다. 자동 정리는 키워드 규칙이며 OCR이나 원격 페이지 읽기는 없습니다.

## 배포와 소스

main 브랜치의 루트에서 GitHub Pages로 게시합니다. .nojekyll은 Jekyll 변환을 끕니다. 빌드·패키지 설치가 필요 없습니다. 상대 경로이므로 프로젝트 하위 경로에서도 동작합니다. manifest의 시작 주소와 서비스 워커 범위는 앱 경로입니다. IndexedDB와 캐시 이름도 앱 경로에 구분되어 있습니다. 웹주소·브라우저가 바뀌면 백업으로 옮겨야 합니다.

업데이트할 때 sw.js의 CACHE 버전을 바꾸세요. 저장소 이름과 백업 schema는 유지하세요. 저장소 파일을 다운받으면 다른 호스팅에서도 독립적으로 운영할 수 있습니다. GitHub가 없어도 기존 기기의 캐시가 보존되어 있으면 오프라인 사용이 가능하지만 재설치·업데이트에는 대체 호스팅이 필요합니다.
