설치 및 보관 안내

내 기기에 머무는 정보 서랍.

기록을 업로드하는 기능이 없습니다.

메시지·사진·비밀번호를 서버로 보내지 않습니다. 외부 AI·광고·분석 도구 없이 기기에서 처리하고, 데이터 전송 API는 보안 정책으로 차단합니다. 처음 설치와 업데이트에는 GitHub에서 앱 파일을 받으며, 이때 IP 주소 등 접속 정보가 전달될 수 있습니다. 원문 링크는 선택할 때 별도 창으로 열립니다.

홈화면에 설치

Chrome / Edge에서는 주소창의 설치 아이콘 또는 아래 설치 버튼을 사용하세요. iPhone Safari에서는 공유 → ‘홈 화면에 추가’를 선택하세요. 설치 후 홈화면 아이콘으로 실행하면 브라우저의 하단 도구막대 없이 열립니다.

오프라인과 기기 이동

추가 인증서나 PC 서버 없이, 인터넷에 연결된 아이폰 Safari에서 이 HTTPS 주소를 열고 공유 → 홈 화면에 추가를 선택하세요. 웹 앱으로 열기 옵션이 있으면 켜세요. 인터넷이 연결된 상태에서 홈화면 아이콘으로 앱을 한 번 더 실행하고, 이 안내에서 오프라인 준비 완료를 확인하세요. 그 후에는 오프라인에서 저장·검색·백업이 가능합니다. 재설치와 앱 파일 업데이트에는 호스팅이 필요합니다. 기존 로컬 앱의 기록은 백업으로 내보내고 새 홈화면 앱에서 복원하세요. 기기·브라우저·웹주소 간 자동 동기화는 없습니다.

저장 공간 보호

기록은 이 주소의 IndexedDB에 저장됩니다. 앱을 닫거나 다시 열어도 남지만, 브라우저 데이터 삭제·시크릿 모드·기기 고장은 별개입니다. 정기적으로 백업하세요. 로컬에 저장된 원본 자체는 암호화되지 않으므로 기기 잠금을 사용하세요.

화면 동작

핀치·더블탭 확대와 페이지 확대 단축키를 가능한 범위에서 제한합니다. 브라우저나 접근성 설정이 제한을 무시할 수 있고 시스템의 홈 표시줄은 웹앱이 제거할 수 없습니다.
